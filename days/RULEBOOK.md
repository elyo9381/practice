# Day01~Day28 공통 운영 규칙 (RULEBOOK)

적용 범위: `/Users/yowon/study/ps/practice/days/day01_*` ~ `day28`

## 1) 불가침 규칙
1. 문제 목록은 교체/하향하지 않는다.
2. 못 푼 문제는 삭제하지 않고 `T+1`, `T+3` 재도전으로 해결한다.
3. 하루 밀려도 포기하지 않는다. 주말에 밀린 문제를 회수한다.
4. 기준 미달이면 난이도를 낮추지 않고 기간을 1~2주 연장한다.
5. 당일 최소 1문제 백지구현은 반드시 수행한다.

## 2) 시간/풀이 규칙
1. 1문제당 40분 제한, 초과 시 해설 확인.
2. 해설 본 문제는 24시간 내 재구현(T+1).
3. 해설 본 문제는 72시간 내 재구현(T+3).
4. 제출 전 시간복잡도 1줄을 적는다.

## 3) 오답노트 규칙
1. 문제당 3줄만 작성한다.
2. 기록 항목은 고정한다: `원인`, `정답 아이디어`, `다음 재발 방지`.

## 4) 일일 완료 기준 (Done Definition)
- [ ] `today_required_done` (당일 필수 문제 완료)
- [ ] `time_limit_applied` (40분 제한 적용)
- [ ] `wrong_note_written` (오답노트 작성)
- [ ] `retry_registered` (`T+1`, `T+3` 등록)
- [ ] `openclaw_report_sent` (일일 보고 전송)

## 5) 일일 보고 스키마 (OpenClaw 점검용)
- `date`: YYYY-MM-DD
- `day_id`: Day01~Day28
- `solved_count`: 정답 수
- `failed_count`: 실패 수
- `implementation_done`: Y/N
- `blank_coding_done`: Y/N
- `retry_t_plus_1`: 문제 목록
- `retry_t_plus_3`: 문제 목록
- `rule_violations`: 없으면 `none`
- `study_minutes`: 총 학습 시간(분)

## 7) 주간 체크 기준
1. 모의코테 최소 1회(2시간)
2. 구현 7문제 이상
3. 24시간 재구현 완료율 90% 이상
4. 문제 교체 없이 계획 유지

## 8) 합격 판정 기준
1. 최근 모의 6회 중 4회 이상 `2문제+` 해결
2. 구현 문제 최근 10개 중 7개 이상 40분 내 해결
3. 오답 재구현률 90% 이상
4. 동일 실수 재발 주 3회 이하

## 9) 일일 운영 강화 규칙 (코치 강제)
1. 시작 선언 필수: 학습 시작 시각을 먼저 공유한다.
2. 40분 하드 타임박스: 문제당 40분 초과 시 즉시 해설 확인 + 원인 기록.
3. 즉시 기록 원칙: 문제 종료 후 5분 내 오답노트 3줄 작성.
4. 백지구현 강제: 매일 최소 1문제는 IDE 자동완성 없이 백지로 구현.
5. 제출 전 복잡도 1줄 강제: 시간복잡도/핵심 자료구조를 한 줄로 명시.

## 10) 주간 운영 강화 규칙
1. 주 1회 2시간 모의코테 고정 (중도 중단 금지).
2. 주간 회고 필수: 일요일에 약점 3개/개선 3개/다음 주 전략 3개 정리.
3. 누적 미완료 3건 이상 시, 다음 주는 신규 문제 비중 축소 후 복기 우선.

## 11) 실패 처리 규칙 (Fail Fast)
1. 같은 유형 2회 연속 실패 시: 다음날 같은 유형 2문제를 교정 세트로 배치.
2. 동일 실수 3회 재발 시: 템플릿(입출력/BFS/DFS/DP 등) 재작성 과제 부여.
3. 문제를 끝까지 못 풀면 '포기'로 처리하지 않고 반드시 T+1/T+3 등록.

## 12) 품질 규칙 (제출형 코드 기준)
1. 변수명/메서드명은 의미 있게 작성한다.
2. 경계값(빈 입력, 최소/최대 크기) 최소 3개를 직접 점검한다.
3. 예외/반례 1개 이상을 스스로 생성해 검증한다.
4. 파일명/클래스명/입출력 형식 불일치로 인한 제출 실패를 금지한다.

## 13) 리포트 강화 규칙
1. 템플릿 빈칸 제출 금지.
2. 미완료 항목이 있으면 원인 + 보충 계획 + 보충 완료 예정 시각 필수.
3. 일일 보고 누락 시 다음날 첫 문제 전 보고부터 제출한다.

## 14) 코치 판정 규칙
1. 규칙 위반 0건: PASS
2. 규칙 위반 1~2건: CONDITIONAL PASS (당일 보완 과제 부여)
3. 규칙 위반 3건 이상: FAIL (다음날 복기/교정 우선 운영)
4. 목표는 '많이 푸는 것'이 아니라 '합격 가능한 정답률/재현성'이다.
